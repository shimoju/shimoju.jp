## 実フォント未取得と拡大方法の提案時の記録（F027）

以下は提案時の記録。ユーザーが採用を承認済み。現在の条件・証拠対応は[T068](../t068/README.md)を参照。

F026はAndroidをOSフォント確認の代表とし、取得不能な必須項目の免除を含めていない。今回「確認できなかった」と報告された。また文字サイズの拡大設定もないため、手順の文字のみ拡大は実施できない。現行条件のままAndroid全体を完了にしない。

提案は、Android Chromeの本文/コードの和文・欧文実フォント名は未取得を制約として記録したまま移行必須条件から外し、拡大確認は端末に提供されるページズーム150%の実測結果を用いること。文字のみの拡大は未実施の制約として残す。本文/コードの表示確認を代替証拠として保持するが、意図したフォントが選ばれたとは主張しない。選択された書体・フォールバックの同定ができない制約が残る。iPhoneの実フォント・文字拡大、その他の完了条件には適用しない。

代案は実フォント取得と文字のみの拡大を必須のまま維持し、確認可能な実機/開発者ツールで確認できるまで待つこと。未取得はテーマの不具合を示すものではない。ユーザーの明示判断まで要件は変更しない。
