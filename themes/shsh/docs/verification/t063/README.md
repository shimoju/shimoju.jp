## 推奨案：代表環境を明示して実機検査を完了する

自動3エンジン検査は継続。実機の完了判定には次の5環境を使い、Safari固有の挙動と4つのOS系統をカバーする。既存の確認済み項目は再試験を要求せず、対象版との対応を保持する。実装変更があれば影響範囲を再検証する。

表示条件（配色、幅、倍率など）は既存記録を用い、追加入力が得られる場合は補足する。実測していない値を端末の仕様から推定しない。各代表環境の証拠は、そのページ・条件に限定する。

この案ではWindows Edge/Firefox、Mac Firefox、iPadの既存結果を補助的な実機証拠として保持し、未確認項目を移行の必須条件から外す。合格へ書き換えるわけではない。これらを含む全端末・全項目の動作保証はしない。Mac Firefoxの追加確認とSafari実フォントの依頼も必須から補助へ変わるため、明示的な判断が必要。

代表環境に残すiOS/Android実フォント等が取得不能なら、取得制約と影響を示して別途判断する。今回の案で未取得をまとめて免除しない。本番HTTP/URL/RSS・共有/スター確認と旧テーマ整理・最終監査も引き続き必要。

real-devices.mdの9環境すべてで詳細手順1〜8を続ける。Mac Firefox描画不一致・Safari Fonts空白には実機操作または取得手段の変化が必要。Windows/モバイルでは未確認欄の追加報告を依頼する。確認済み項目は保持し、未確認項目が解消するまで本番マージを待つ。
