## 実フォント未取得の扱い（F028、未承認）

F026はiOS SafariでOS固有実フォントを確認する条件。F027はAndroid限定なのでiPhoneへ自動適用しない。今回の未取得を合格にはできず、この項目だけ完了判定の判断が残る。

提案はiPhone Safariの本文/コード和欧文実フォント名に限り、未取得を制約として残し今回の移行必須条件から外すこと。既存の本文/コードの表示確認は保持するが、選択されたフォントとフォールバックが意図どおりとは主張できない。他の項目や環境へ免除を広げない。

代案は実フォント取得を必須のまま保持し、取得可能な実機/開発者ツールで確認できるまで待つこと。ユーザー判断まで要件とiPhone全体の未完了を維持する。
