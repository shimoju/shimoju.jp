# T006: 記事本文・日付・コード操作

記事ヘッダー、本文部品、見出しアンカー、横スクロール表、コード表示とコピーを実装した。T005の共通日付処理を利用する。R001は未提出であり、カバー・本文メディアはT007、共有はT008、代表画面を揃えた全体レビューはT009に残る。記事末尾・固定ページ等の全画面展開は承認後のT010で行う。

## 責務

- `single.html`は記事ヘッダーと本文枠、`dates.html`は日付表示を担当する。固定ページのshowDates=false、日付なし、同じ暦日の更新日非表示を扱い、比較と表示の両方にT005のサイトタイムゾーン変換を使う。明らかなshowDates型違いはエラー。
- `prose.css`は段落・見出し・リスト・引用・表・脚注、`code.css`はインラインコード・コードブロック・ラベル・コピー状態を担当する。配色は既存の役割別トークンとHugo生成の公式Chroma宣言。コードに独自の色は追加していない。本文の表とChroma行番号用の表を分け、本文表のセル寸法を行番号へ適用しない。
- 見出しrender hookはHugoのAnchorをそのまま使う。表render hookはMarkdownの左右・中央揃えをクラスへ変換し、名前付きのキーボード操作可能なスクロール領域で囲む。
- コードrender hookは`transform.HighlightCodeBlock`で言語・filename・行番号・強調を扱う。未知言語はtextへフォールバックする。filenameはラベルとして表示し、HTMLの未知属性としては出力しない。[Hugo code block hooks](https://gohugo.io/render-hooks/code-blocks/)
- `copy.ts`はdefer付きの別Pipes出力で動く。初期配色の同期実行と分離した。本文pre内のコードを複製し、インライン行番号を除去する。表形式の行番号はコード列のpreを選ぶ。ラベル・番号を混ぜず、改行・日本語・HTML記号を保存する。成功通知は3秒で戻り、失敗は選択コピー／再試行を案内する。ホバー・フォーカス・タップで表示し、Escape・外側タップ・横スクロールで閉じる。Escape時にボタンへフォーカスがある場合はpreへ戻す。診断URLパラメーターは扱わない。
- JS無効時にはコピーを非表示のままとし、本文・コード選択・表スクロール・脚注リンクを利用できる。

## 検証

`pnpm check:prose`で、公開日補完、タイムゾーンをまたぐ同日／別日の更新、固定ページの非表示、記事では日付を維持すること、型エラーを検証した。元の実記事`2023/06/22/hugo-and-cloudflare-pages`を改変せず隔離サイトへコピーし、本文部品fixtureとともに生成HTMLを検証した。テーマを外した同版Hugoの標準出力とも見出しIDが一致した。

`tests/prose.spec.ts`で3エンジンのコピー内容、実際のTab移動とEscapeのフォーカス復帰、失敗・再試行・3秒復帰、タッチ、JS無効、脚注移動、幅のある表を検査する。1280px／400px・両配色で本文部品の書式とモックを比較し、axeの違反はChroma内の合意済み色コントラストだけに限定して記録する。

実記事全文は同じMarkdownから生成し、凍結モック`article-hugo.html`と各本文ブロックの幅・高さ・相対位置を3エンジンで照合する（差0.05px未満）。Chromiumの両幅・両配色の本文画像を`t006-prose-images/`に保存した。画像を目視でも比較し、段落・見出し・コードの欠落や局所スクロール以外の切れがないことを確認した。これは本文部分の比較であり、ページ全体のR001を代替しない。

最終結果は`t006-check.log`を参照。実機Safari／OSフォント・実Clipboard環境の確認は後続の実機検証に残る。

## 検出と是正

F005: HTML-validate既定のID命名規則はHugo標準脚注ID`fn:1`／`fnref:1`を拒否した。Q32の標準ID保持に従い、`valid-id`をHTML5準拠の`relaxed: true`へ設定した。ID検査の無効化ではなく、非空・空白なしという標準の制約を検査する。検査fixtureで空文字と空白入りIDを引き続き拒否することも確認した。[HTML-validate valid-id](https://html-validate.org/rules/valid-id.html)

開発中のHTML検査では、Hugoが既に出すtabindexの重複、Chromaの表の省略tbodyも検出して是正した。コピーの名前付きpreはgroup、本文表のスクロール領域はsectionを使う。複数の表を識別できるよう、読み上げ名に表の連番を付ける。整形で条件付きclassの空白が消える箇所は、不要なunlabelledクラスを削除し、コードのラベルも一つの文字列として生成して整形に影響されないようにした。

初回ブラウザ検査では、動き続ける検査時計に2999msを加えたため3秒境界を超えたことと、引用内コードを本文直下コードと比べたことが失敗の原因だった。時計を停止し、同じ親要素の部品を比べるよう是正した。実記事全文の追加検査ではWebKitで1行の差を検出し、比較用サイトのlang=enを本番と同じjaへ揃えると一致した。許容幅は広げていない。
