# T049 Mac Chrome / Safariのコピー内容照合

2026-09-18、Codexがネイティブアプリを操作した。macOS 27.0（26A428）、Chrome 153.0.8010.53、Safari27.0（22625.1.29.11.27）。アプリ版はInfo.plistから取得。固定preview268bbb0の[開発環境記事](https://6f52990f.shimoju.pages.dev/2026/09/01/development-environment-2026/)を使用。

## 手順と結果

1. 送信・保存処理を持たない一時ローカルHTMLのtextareaを開き、別の専用タブで記事を開く。
2. 最初のCopy codeをクリックし、Code copied.の通知を確認する。
3. 用意済みのローカルタブへ移り、入力欄へネイティブCmd+Vで貼り付ける。
4. AXの入力値と記事Markdownの最初のコードを比較する。コードは235文字で、Chrome・Safariとも完全一致した。クリップボード内容そのものは証拠へ保存しない。
5. 専用タブ2つずつと一時HTMLを削除した。

| 環境                | 結果              | 証拠                   |
| ------------------- | ----------------- | ---------------------- |
| Chrome153.0.8010.53 | 235文字の完全一致 | chrome-copy-final.json |
| Safari27.0          | 235文字の完全一致 | safari-copy.json       |

## 再試行と限界

Chromeの最初の2回はCopy code通知があったが、貼り付け内容が原文と一致しなかった（chrome-copy.json、chrome-copy-retry.json）。操作中の別のクリップボード更新か操作ツールの経路の差かは特定していない。内容を記録・再出力せず、コピーから貼り付けまでを1つのツール呼び出し内で連続操作し、再試行で完全一致を確認した。最初の不一致をテーマの不具合と断定しない。

Safariでは最初の画面外のAXクリック直後に通知を取得できず、画面内へスクロールされたコードのボタンを操作して通知を取得した。画面外のツール操作を通常のユーザークリックとして数えず、可視ボタンのコピー内容一致を結果とする。

T028/T039で使ったブラウザセッションのvirtual clipboard結果とは異なり、今回はネイティブアプリの貼り付けを使った。T039のコピー内容照合は解消するが、フォント・文字拡大・JS無効・動画・外部埋め込みなどの未確認項目はT015で継続する。現行安定版との照合も別途必要。
