## 固定する確認条件と人の確認

画像比較はこのMacの同一OS・実フォント・固定Playwright版を用い、1440×1000と390×844、ライト/ダークを基本とする。実行時の正確なOS・ブラウザ版・フォントを証拠に追記する。125%・200%の文字拡大、hover/touchとキーボードも別条件として確認する。画像の一致だけで操作やコード構造の合格とはしない。

性能はT016に端末相当条件・回線・CPU・cold cache・各5回の測定を定めた。LCP 2.5秒・CLS 0.1の目標を維持し、全試行と中央値を記録する。実環境の達成保証とは区別する。

人の明示判断はR001/R002と未合意の表示・操作変更で必要。PC/モバイル実機のOSフォント、Cloudflareアカウント内の実設定など手元で検証できない部分は、対象URL・手順・記録項目を準備して依頼する。Playwright WebKitを実Safari確認に置き換えない。未実施は合格記録にしない。
